# Black-Ink Bestiary — Logo Brief

## Brand Name

**Black-Ink Bestiary**

## Tagline

**Fantasy Monsters in Their Natural Habitat**

## Core Idea

The logo should immediately communicate:

- black ink
- fantasy monsters
- coloring-book line art
- a slightly mysterious bestiary / field-journal feel

It must work in **pure black on white** because the brand itself is built around black-line artwork.

## Preferred Mark

A simple black-ink emblem that combines one of these concepts:

1. **Monster eye emerging from an ink blot**
2. **Ink bottle / quill whose splash forms a monster silhouette**
3. **Claw marks formed by brush or ink strokes**
4. **Open bestiary book with a subtle monster silhouette rising from the pages**

## Best Direction for v1

**Ink blot + monster eye**

Reason:
- recognizable at small sizes
- simple enough for favicon/app icon
- easy to print
- does not compete with the artwork
- avoids looking like a generic fantasy game logo

## Style

- monochrome
- bold silhouette
- minimal interior detail
- slightly hand-inked
- mature fantasy tone
- not horror-gore
- not cute/cartoon
- no faux-medieval overload

## Wordmark

Use:
- `BLACK-INK` as the strongest line
- `BESTIARY` directly below or beside it
- optional tagline in smaller type

The mark must also work without the tagline.

## Must Avoid

- D&D logo or ampersand
- Wizards of the Coast trade dress
- dice as the main symbol
- dragons as the only identity
- tiny detailed crest that disappears at favicon size
- gradients or color-dependent effects
- overly ornate unreadable fantasy fonts

## Required Variants Later

1. Full horizontal logo
2. Stacked logo
3. Icon-only mark
4. Pure black version
5. White/reversed version for dark UI

## Production Rule

Do not delay the page-generation system waiting for a perfect logo.

Use the text wordmark **Black-Ink Bestiary** until the final emblem is approved.
